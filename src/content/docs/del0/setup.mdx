Du behöver en miljö där du kan köra AI-agenter mot din kod. Kursen stödjer **Linux, macOS och Windows via WSL**.

## Verktyg

Följande verktyg används i kursen just nu. Verktygslandskapet ändras snabbt och listan kommer sannolikt att vara förändrad nästa år.

* **Terminal** – din arbetsplats.
* **[Claude Code](https://claude.com/claude-code)** – kodagent från Anthropic.
* **[Codex](https://openai.com/codex/)** – kodagent från OpenAI.
* **[OpenCode](https://opencode.ai/)** – öppen kodagent som kan använda många olika modeller.
* **[herdr](https://herdr.dev/)** – ett program för att köra flera kodagenter.
* **[Tailscale](https://tailscale.com/)** – privat nätverk mellan dina maskiner. I kursen används det främst för att visa hur körning av agenter kan **distribueras över flera maskiner** med herdr.

## Kostnad

Det är ännu inte klart vem som betalar för åtkomst till verktygen och modellerna, skolan eller studenterna.
